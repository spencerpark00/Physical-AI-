# 로봇 시뮬레이션 시연 설명서 — 엔진 카울 사각지대 검사

> **한 줄 요약**: 사람이 구조적으로 접근할 수 없는 항공기 엔진 내부 결함을,
> 이동형 협동로봇(MOBY + Indy7)이 좁은 액세스 슬롯으로 진입해 촬영하는 과정을 물리 시뮬레이션으로 증명한다.

---

## 1. 실행 방법

```
cd C:\Users\User\robotsim
py -3.11 demo_engine_cowl.py
```

| 조작 | 기능 |
| --- | --- |
| **R** | 시연 처음부터 다시 재생 |
| **V** | 녹화 시작 / 중지 (mp4 파일로 저장) |
| **Ctrl + 마우스 드래그** | 시점 회전 |
| **마우스 휠** | 확대 / 축소 |
| 창 닫기(X) | 종료 |

**자동 녹화 모드** — 실행과 동시에 녹화하고 1회 재생 후 자동 종료:
```
py -3.11 demo_engine_cowl.py --record
```
> mp4 파일은 `C:\Users\User\robotsim\` 폴더에 `demo_engine_cowl_날짜_시간.mp4` 로 저장됩니다.
> 이 파일을 팀원에게 전달하면 됩니다 (팀원은 PyBullet 설치 불필요).

## 3. 시연 흐름 (단계별)

### 【1단계】 사람이 먼저 시도한다 — 그리고 실패한다

**화면 문구**: `[1] Worker tries: shoulder blocked by cowl ring`

- 살구색 **팔 + 어깨**가 엔진 입구를 향해 접근합니다.
- 팔은 들어가지만, **어깨가 카울 입구 링에 걸려 멈춥니다.**

**화면 문구**: `[1] BLOCKED - arm cannot reach 30cm inside`

- 멈춘 자리에서 **앞뒤로 밀어보는 동작**이 반복됩니다 (더 넣으려는 시도).
- 손끝에서 결함까지 **빨간 선**이 그어지고 **"cannot reach"** 문구가 표시됩니다.
  → *팔을 최대한 뻗어도 결함까지 닿지 않는다*는 것을 시각적으로 보여주는 장면.
- 결국 팔을 빼고 물러납니다.

> **💡 설명 포인트 (발표 시)**
> "높아서 못 하는 게 아니라, **구조 자체가 사람 팔을 막습니다.**
> 팬 블레이드가 정면을 가리고, 카울 링에 어깨가 걸리고, 결함은 40cm 안쪽에 있습니다.
> 사다리를 놓아도, 팔이 긴 사람이 와도 해결되지 않는 문제입니다."

---

### 【2단계】 로봇이 투입된다

**화면 문구**: `[2] Robot: slim wrist enters the 15cm gap`

- Indy7이 대기 자세에서 움직여 **카울 입구 앞에 정렬**합니다.
- 손끝(엔드이펙터)이 액세스 슬롯 방향을 정확히 향합니다.

> **💡 설명 포인트**
> "로봇 손목은 **9.6cm**입니다. 사람 어깨가 못 지나가는 슬롯을 통과할 수 있습니다."

---

### 【3단계】 사각지대로 진입한다

**화면 문구**: `[3] Entering engine cowl...`

- 로봇팔이 **좁은 액세스 슬롯을 통과해** 엔진 내부로 들어갑니다.
- 팬 블레이드와 링 사이의 좁은 통로를 지나 **40cm 깊이까지 진입**합니다.
- 오른쪽 위 **로봇 시점 카메라**로 내부가 어떻게 보이는지 실시간 확인 가능합니다.

> **💡 설명 포인트**
> "이 진입 경로는 물리 시뮬레이션으로 **충돌 검증을 마친 경로**입니다.
> 로봇이 구조물에 부딪히지 않고 실제로 통과 가능하다는 것이 계산으로 확인됐습니다."

---

### 【4단계】 결함을 촬영한다

**화면 문구**: `[4] CAPTURING corrosion image`

- 로봇 손끝이 **결함 바로 앞(약 9cm)에서 정지**합니다.
- **플래시가 3번 터집니다** (촬영 연출).
- 로봇 시점 카메라에 부식 결함이 정면으로 잡힙니다.

**화면 문구**: `[5] Image captured -> sent to dashboard`

> **💡 설명 포인트**
> "촬영된 이미지는 곧바로 **관리자 대시보드의 지식그래프로 전송**됩니다.
> 앞서 보신 MRO Copilot의 '지식' 메뉴에 검증사례로 축적되는 것과 연결되는 지점입니다."

---

### 【5단계】 복귀

- 로봇이 왔던 경로를 되짚어 **후퇴 → 대기 자세로 복귀**합니다.
- **화면 문구**: `DONE - press R to replay`

## 4. 시뮬레이션 검증 결과 (기술 근거)

발표에서 "그냥 애니메이션 아니냐"는 질문에 답할 수 있는 근거입니다.

| 검증 항목 | 결과 |
| --- | --- |
| 로봇 모델 | **뉴로메카 공식 Indy7 URDF** (github.com/neuromeka-robotics/indy-ros2) |
| 접근 지점 도달 정확도 | 오차 **0.0003m** (0.3mm) |
| 진입 지점 도달 정확도 | 오차 **0.0000m** |
| 촬영 지점 도달 정확도 | 오차 **0.0000m** |
| 구조물 충돌 | **0건** (전 구간) |
| 역기구학(IK) | PyBullet 내장 IK로 관절 각도 자동 계산 |
| 물리엔진 | Bullet Physics (충돌 검출 실제 수행) |

> 즉, **"로봇이 이 좁은 통로를 실제로 통과할 수 있다"** 는 것이
> 임의로 그린 그림이 아니라 **물리 계산으로 확인된 결과**입니다.

## 5. 발표 시나리오 (3분 버전)

1. **문제 제기** (30초)
   "엔진 내부 부식은 정기 점검 항목이지만, 카울을 분해하지 않으면 사람이 접근할 수 없습니다."
   → 1단계 재생 (사람 팔이 막히는 장면)

2. **해결 방식** (60초)
   "MOBY가 로봇을 현장까지 이동시키고, Indy7의 얇은 손목이 액세스 슬롯으로 진입합니다."
   → 2~3단계 재생

3. **결과** (60초)
   "40cm 안쪽 결함을 촬영하고, 그 이미지가 대시보드 지식그래프로 축적됩니다."
   → 4~5단계 재생 + 관리자 대시보드 지식 탭 연결

4. **신뢰성** (30초)
   "이 경로는 뉴로메카 실제 로봇 모델로 충돌 검증을 마쳤습니다." (4장 표 제시)
